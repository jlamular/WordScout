# WordScout

**Discover new words. Expand your vocabulary.**

WordScout is a simple vocabulary discovery app built with React. Search for English words, explore their definitions, and discover a new word every day.

## Features
- **Word Explorer** – Search words and view their definitions.
- **Word of the Day** – Discover a new word daily.

## Built With
- React
- JavaScript
- Vite
- CSS
- Fetch API

## APIs
- [Free Dictionary API](https://dictionaryapi.dev/)
- [Word of the Day API](https://wordoftheday.freeapi.me/)

## Run Locally
```bash
git clone https://github.com/jlamular/WordScout.git
cd WordScout
npm install
npm run dev
```
